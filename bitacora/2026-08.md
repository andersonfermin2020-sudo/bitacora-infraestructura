# Agosto 2026 — Punto de partida

Entrada inicial de la bitácora, al comenzar el 7mo semestre. Resume lo 
acumulado hasta ahora, antes de empezar el registro mes a mes.

## 🐍 Python
- Fundamentos, estructuras de control y de datos
- POO completa: clases, herencia simple/múltiple, MRO, polimorfismo, encapsulamiento
- Manejo de excepciones, validación de datos y diseño de sistemas CRUD
- Persistencia (JSON, SQLite), arquitectura MVC y en capas; ciclo de vida SDLC
- Automatización: regex, módulos `os`/`sys`/`subprocess` → ver [`python/`](../python)

## 💻 Bash
- Estructura de script, variables, entrada de datos, aritmética
- Condicionales (`if`, `case`), bucles (`for`, `while`), comodines
- Funciones (parámetros, retorno, validación), arrays
- Filtros de texto: `grep`, `sed`, `awk` para procesamiento de líneas
- Jobs, gestión de procesos y manejo de señales (`trap`)

## 🔧 Git & GitHub
- Flujo completo: commits, ramas, merges, resolución de conflictos
- Herramientas avanzadas: rebase (interactivo y de actualización), stash, 
  cherry-pick, bisect, hooks, submodules, tags
- Recuperación con reflog, alias personalizados, buenas prácticas de `.gitignore`
- Modelos de flujo de trabajo: GitFlow vs GitHub Flow, releases en GitHub

## 🐧 Linux
- Referencia general: archivos, permisos, usuarios/grupos, procesos, 
  búsqueda (find/locate), redirecciones, pipes, backups con tar
- Gestión de contraseñas y políticas de expiración, automatización con cron
- Administración de servidores (Ubuntu Server): particiones, LVM, SSH 
  remoto, kernel, gestión de paquetes (apt)
- Inspección de hardware desde terminal, servicios: SysV init vs systemd

## 🌐 Redes (CCNA)
- Modelos OSI/TCP-IP; capa de aplicación en profundidad (DNS, HTTP/HTTPS)
- Subneteo IPv4 e IPv6
- Switching: VLANs, VTP, DTP, CDP, STP, port security
- Enrutamiento: estático, InterVLAN (los 3 métodos), RIPv2, NTP, 
  distancia administrativa vs métrica
- Configuración segura de routers Cisco (SSH, hardening, banners)
- Proyecto integrador de 10 sedes → [`ccna-redven-network-lab`](https://github.com/andersonfermin2020-sudo/ccna-redven-network-lab)

## 💾 SQL
- Modelado de datos: diagrama entidad-relación, cardinalidad, normalización
- DDL/DML, funciones de string/fecha/matemáticas, `EXISTS`/`NOT EXISTS`
- Todos los tipos de JOIN, subconsultas, funciones de agregación
- Índices, vistas y orden de ejecución interno de una consulta
- Practicado sobre la base Northwind con SQLite
